## 🚀 Featured Projects

### 🌿 [Ondelaga Care](.) — On-Device Plant Health Diagnosis App &nbsp;`🚧 In Development`
Android app that diagnoses nutrient deficiencies and diseases in *Ondelaga* (Centella asiatica) leaves — entirely offline, on-device.
- 3-stage ONNX pipeline: leaf detection (EfficientNet-B0) → species recognition (MobileNetV3-Large) → 8-class health diagnosis (MobileNetV3-Large)
- Runs 100% offline via ONNX Runtime — no server or internet connection required
- Severity estimation, condition-specific recommendations, English/Kannada localization, and text-to-speech output
- Local diagnosis history & progress tracking via a Room database

`Kotlin` `Jetpack Compose` `ONNX Runtime` `MobileNetV3` `EfficientNet-B0` `Room DB`

### 🧠 [ResuMatch](https://github.com/Sanjana-nn2/ResuMatch) — AI Resume ↔ Job Description Match & Gap Analyzer
AI-powered tool that scores a resume against a job description and surfaces skill gaps using semantic similarity.

`React` `Node.js` `PostgreSQL` `FastAPI` `Sentence Transformers` `Android`

### 🔗 [Linkly](https://github.com/Sanjana-nn2/url-shortener) — Full-Stack URL Shortener
Production-style URL shortener with Base62 short-code generation, URL validation and redirection.
- PostgreSQL storage with Redis caching and rate limiting
- Click analytics tracking device, browser, OS, country, and referrer data
- Frontend, backend, PostgreSQL, and Redis containerized with Docker Compose; automated backend testing

`React` `Node.js` `Express` `PostgreSQL` `Redis` `Docker`

### 📊 [AI-Powered Placement Preparation Tracker](https://github.com/Sanjana-nn2/placement-preparation-tracker)
Full-stack MERN app for managing placement preparation, with secure JWT authentication and RESTful APIs.
- Interactive dashboard with analytics, task planner, Pomodoro timer, and company tracker
- Complete CRUD operations with a responsive UI for real-time progress tracking

`React` `Node.js` `Express` `MongoDB` `JWT` `Tailwind CSS`

### 🍽️ [CampusEats](https://github.com/Sanjana-nn2/CampusEats) — Food Discovery & Ordering Platform
Full-stack platform for students to discover nearby college canteens and restaurants, compare dishes and prices, manage favorites/cart, and place orders. Deployed on Render with MongoDB Atlas.

`React` `Vite` `Tailwind CSS` `Node.js` `Express` `MongoDB` `JWT`
